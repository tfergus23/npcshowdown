ABOUT

So what even is this place?

NPC Showdown is a place where you can create teams for NPC Pokemon trainers and then have them fight each other. The trainers are AI controlled (similar to the games). You can either have them fight a singular battle, or pit a bunch of them against each other in a round robin tournament.

Is this affiliated with Pokemon Showdown?

Nope! The name is simply a reference. This is a hobby project written entirely by one person. Pokemon Showdown's code is not being used anywhere in this project.

So how do I get started?

You can start by running a tournament with the sample trainers to see what you're getting into.
